# となりて｜クライアント確認用HP（デモ）

## 開き方
1. ZIPを解凍し、フォルダ `tonarite-website` をVSCodeで開く。
2. `index.html` をChrome等のブラウザで開く。VSCodeの「Live Server」拡張機能も使用可能。
3. 各ページへの移動、メニュー、4言語切替、寄付金額の選択、フォーム画面を確認する。
