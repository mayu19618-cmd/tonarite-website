# となりて｜水彩デザイン HTMLサイト

## 開く方法
`index.html` をSafariまたはChromeで開いてください。Local/WordPress/PHPは不要です。

## 構成
トップ、団体概要、プロジェクト、寄付、お問い合わせ、活動報告一覧・詳細、情報公開・資料の各ページ。既存の文章やデザイン構成を維持し、いただいた水彩イラスト10点を assets フォルダに収録しています。

## PDFを掲載する方法
1. PDFを `pdf/` フォルダにコピー
2. `pdf-links.js` を開いて、`rules`, `plan`, `report` の値にそれぞれ `pdf/ファイル名.pdf` と入力
3. `disclosure.html` を開いて確認。未設定のものは資料準備中と表示されます。

## GitHub Pagesにアップロード
フォルダの中身をリポジトリのルートにアップロードしてください（index.htmlが最上位）。

## 本番公開前の注意
お問い合わせフォームはデモのため送信不可、寄付決済も未接続です。実際の相談や支払いには使用しないでください。記事にはサンプル原稿が含まれます。支援実績、人物情報、翻訳文は必ず公開前に確認してください。HTML版にはスタッフ向け記事投稿管理画面はありません。
