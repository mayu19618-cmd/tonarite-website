# となりて｜HTMLサイト（ロゴ反映版）

提供された最新版のHTML・JS・CSSと水彩画像をもとに、全ページのヘッダーとフッターに指定の「両手で家を包む」ロゴを反映しました。本文・ページ内容・ナビ項目は保持しています。

## 確認方法
ZIPを解凍し、`index.html` をSafariやChromeで開いてください。PHPやWordPressは不要です。

## GitHub Pages
ZIPはそのままアップロードせず、解凍した中のファイルと `assets/`, `pdf/` をリポジトリ直下にアップロードしてください。`index.html` が最上位です。

## PDF
`pdf/` に資料を置き、`pdf-links.js` の rules / plan / report にPDFパスを設定してください。
