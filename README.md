# となりて｜クライアント確認用HP（デモ）

## 開き方
1. ZIPを解凍し、フォルダ `tonarite-website` をVSCodeで開く。
2. `index.html` をChrome等のブラウザで開く。VSCodeの「Live Server」拡張機能も使用可能。
3. 各ページへの移動、メニュー、4言語切替、寄付金額の選択、フォーム画面を確認する。

## 注意事項
- 本ファイルは **フロントエンドのデモ** です。フォームは送信・保存せず、決済も一切実行しません。
- 写真、スタッフ情報、代表メッセージ・経歴等はプレースホルダーです。正式な素材と確認済み文章に置き換えてください。
- 中国語は簡体字です。翻訳文は仮訳であり、公開前にチェックが必要です。
- Recruit は専用ページを未作成とし、トップから一般お問い合わせへリンクしています。
- お悩み相談フォームは安全性を確保した本番用システムの設計・審査が必要です。このデモをそのまま公開して相談受付に使わないでください。
- WordPress対応はクライアント確認後に別途行います。
- 写真を使わずCSSで布地風のバナーを仮再現しています。Figmaの画像素材を取得して差し替えると再現度が上がります。

## 活動報告・コラム（追加）
- `articles.html`: 記事一覧、カテゴリーフィルター
- `article.html?id=...`: 記事詳細
- `articles-data.js`: 記事データ。サンプル原稿4件を収録。**実際の活動報告ではありません**。
- `articles.js`: 記事表示プログラム
- トップページの「活動報告・コラム」に最新3件を表示。

### 記事の追加方法（試作品）
`articles-data.js` の配列に `id`, `category`, `image`, `title`, `summary`, `body` を持つオブジェクトを追加し、GitHubにコミットします。新しい順に冒頭へ挿入してください。
この試作品は投稿管理画面・権限管理・サーバー保存を持ちません。週1回のスタッフ投稿を簡単にするCMSは、本番構築時に別途導入します。

### 注意事項
支援者を特定できる個人情報や未確認の活動実績を記事に掲載しないでください。
